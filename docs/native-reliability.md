# 原生调用可靠性

本轮针对地址转换、数值配置和离线预览的实际问题完善接口。支持情况以当前安装的FStudio版本及工具schema为准；本机验证版本为3.0.15685.0。

## 地址与数值

`fstudio_address_configure_local` 使用当前工程的原生本地寄存器工厂。将保持寄存器字内位转为本地位地址时，先清除字内位标志，再写设备和寄存器身份，最后恢复数据类型。规则刷新后重新取得当前Raw回读；启用的配方、标签及高级引用仍拒绝，避免误改另一种寻址模式。

`fstudio_address_configure_modbus_rtu` 绑定工程中已启用的标准Modbus RTU主站端口，设备UUID由当前工程读取。地址使用驱动的一基4X字地址；位信号另给bit0～15，不能套用线圈地址。站号、数据类型、字宽、地址基准及现场点表分别核对，不根据控件编号猜测控制器。

`fstudio_numeric_configure_zoom` 以完整原生DTO设置倍率和偏移，支持正负有限数。原始值、显示类型、小数位及缩放可能共同影响结果，不能把设置小数位和乘倍率当成同一个操作，也不能重复缩放。

`fstudio_numeric_configure_limits` 为当前数值控件初始化完整上下限，关闭溢出替代和闪烁。在已验证版本中，关闭UseLimit会丢弃限值子对象并导致编译器空对象访问；该接口要求UseLimit=true。这是版本特定兼容方式，不能推断所有FStudio版本或数值类型都需要同样处理。当前参数范围见schema；其他类型先验证原生能力。

所有这些接口只配置工程模型，不读取或写入控制器。保存、重开和原生编译分别验收；属性回读成功不能替代编译成功。

## 成功编译产物的离线预览

1. 保存当前工程，执行`fstudio_build_start`，查询原`build_id`至终态。
2. 确认`compiler_success=true`及清理完成，将同一个ID传给`fstudio_simulate_compiled`。
3. 入口重新比较当前完整源码清单、工程身份和归档输出哈希。未保存页面、其他工程、已存在的模拟器或Bin重解析点会被拒绝。重开工程可能改变原生系统数据库，需要重新编译；旧`source_unchanged`不能替代当前核对。
4. 通过官方完整参数启动FCS/FSGUI，RunMode固定为SimPlc，Debug固定为N。保留temp记录，不执行“清除记录”操作，不重复编译，也不接受自定义程序或命令行。
5. 在模拟器中操作所需页面，等待画面刷新，使用`fstudio_simulator_capture`取得真实客户区截图。逐张核对标题、目标控件、最大位数、负号、单位和主要状态；启动返回成功不等于运行验收。
6. `fstudio_simulator_close`向已核实归属的模拟窗口请求正常关闭；确认退出后，用`fstudio_simulator_helper_close`关闭本入口拥有的后台辅助进程。请求关闭和核实退出是两个不同状态。

输出按本次清单覆盖生成文件，保留未列出的历史Bin文件及全部temp记录。复制中途失败会阻止启动，但不是整个Bin的事务回滚；修复原因后可重试同一已验证归档。该接口不下载设备、不提供在线模拟模式。

原生`fstudio_simulate_offline`保留厂商模拟流程，可能弹出原生记录处理对话框；其辅助进程与编译归档入口的归属记录不同。工具不按进程名批量终止，也不接管外部进程。需要自动操作某个产品的按钮时，应另外按真实控件和交互实现场景脚本；通用工具不假设页面数量、菜单布局或消音按钮。

## 调用与排障

`visible_start`返回starting后先等待真实只读状态就绪。页面切换、草稿配置/提交、保存及重开由一个操作者连续完成，避免其他客户端改变活动上下文。超时后继续查询原任务ID；传输结果未知时先核对状态或目标文件，不重复提交变更。重开后依据稳定名称或UUID重新取得模型句柄。

更多版本边界和验收方法见[技能排障说明](../skills/fstudio-skills/references/call-troubleshooting.md)与[原生模型说明](../skills/fstudio-skills/references/fstudio-native.md)。

## 验证范围

本轮可复现回归位于tests/，覆盖协议/注册、模型访问、绘图契约、完整ZIP、倍率参数，以及归档预览的源码变化、输出篡改、工程不匹配、已有模拟器、重解析点、复制失败和记录保留。发布前重新构建x86原生桥和宿主DLL，运行统一测试，并独立解压技能包检查服务入口。

统一入口27项全部通过，无跳过；真实DLL反射另在其中覆盖15项编译所有权保护、只读分类、原有build分发与API版本/能力声明检查。服务及宿主API版本为0.5.0，厂商DLL验证版本仍为3.0.15685.0，二者含义不同。编译期间不允许启动或关闭预览、也不允许归档安装预检越过项目保护；截图和画布导出仍可只读执行。

维护验证另外完成代表性工程的保存重开、原生编译、字内位转本地位的有效性回读及1024×600离线运行截图检查。这些本机工程、截图、接口数据和路径不随源码分发；不能由此宣称所有接口和参数组合都完成了同等运行验证。

未验证真实串口通信、控制器动作、设备下载或现场触摸屏运行。离线测试数据和真实测量值应分别标记。更新服务脚本与宿主DLL后，重新连接MCP并加载匹配宿主；仅重连服务不会替换运行中的DLL。
