# 设计与原生组件映射

## 原型先变成可执行约束

读取原型实际的画布、布局、字体、图层和组件状态。小改动仅提取相关区域；跨页面制作再提取共用设计规则。用户要求先看各页时，在其认可前不要批量切片和实现。

不要把历史项目的深色、科技风、设备照片或菜单数量视为通用审美。按照用户参考保留视觉语言；工业界面优先让异常、阶段、可操作性和反馈可辨识。若用户要求最新标准或最新设计经验，查询当前官方资料并标注版本；不要把个人风格偏好包装成强制标准。

使用原生分辨率设计；模拟器窗口尺寸可能包含标题栏和系统缩放。比较时使用等比例的内容区域，不把两张整窗口截图直接比较。Figma 像素、原生字体单位与系统缩放不是同一单位，应以实际测试文本确定换算关系。

## 公共层的职责

建立一张所有权表即可：

| 内容 | 推荐归属 | 要验证的行为 |
| --- | --- | --- |
| 页面底色、全局标题、导航、时间等 | 原生公共页面或平台支持的共享机制 | 所有目标页面显示一次，层级正确 |
| 当前菜单状态、全局通信提示 | 公共组件中的动态状态 | 切页、跳页、返回时都更新 |
| 当前页面的图表、工艺图、表单 | 子页面 | 不携带重复的顶栏和背景切片 |
| 弹窗、键盘、特殊全屏页面 | 按平台机制决定 | 公共层不遮挡弹窗和触摸区域 |

公共背景颜色属性未必等价于公共背景图元。若实测属性不呈现，再用公共页面底层背景图元，并检查是否遮住子页面、报警或键盘。不要给每页再加同色底图掩盖共享机制错误。

迁移时按稳定标识去重，保持原生保留页和系统弹窗。不得把公共页编号直接当普通叠加窗口编号使用，除非当前版本明确支持。

## 元素如何落地

| 设计元素 | 实现选择 | 避免的替代 |
| --- | --- | --- |
| 标题、注释、单位、多语言文字 | 原生文本及语言资源 | 文字切片、图片中的数值 |
| 实时数值 | 原生数值显示，配置类型/缩放/格式 | 静态数字、无绑定的模拟值 |
| 可编辑参数 | 原生数值或字符输入、键盘、限值与写入语义 | 只画矩形输入框 |
| 菜单、状态按钮 | 带状态图片/文字的原生指示或按钮控件，并显式配置动作 | 静态图标上叠多个不可维护的点击层 |
| 圆环、进度、趋势、报警 | 平台支持的原生动态控件 | 把动态变化烘焙为整张图 |
| 设备轮廓、复杂插画 | 独立透明素材 | 含背景、标签和反馈状态的整页图 |

“指示灯”不自动具有写入或切页动作；检查所选原生控件是否能承载所需行为。纯反馈灯与控制按钮的语义不能混淆。需要瞬时、置位、复位、切换或按下/松开动作时，按控制协议明确选择。

## 字体与对齐

- 在代表性控件上测试中文、英文、数字、符号、负号、小数和最长翻译。确认字体实际存在及原生字库能使用所选样式；字体名可用不代表编译出的字库正确。
- 配置数据类型、整数位、小数位、字体和字重后，保存重开回读尺寸。原生控件可能依据最大显示内容重新计算 MinWidth/MinHeight。
- 数字、单位和说明分开管理，但作为一组布局。按最终回读宽度及数字基线排列单位，不按原型示例值的字符宽度硬编码。
- 负值、最大值、零值和小数显示都要看；零值可能省略小数位，不能仅用零值判断格式正确。
- 需要与原型一致的左对齐时优先保留对齐意图；如原生尺寸约束迫使调整，说明具体偏差，不声称像素级还原。
- 发现缺字或裁切，先核对源文本、语言状态、边界、重叠、字库和字体样式。不要未经对照试验就断言是字号、编码或字体库 ID 所致。

## 素材与工艺图

透明素材导出时检查实际 alpha 通道、非透明边界、原始尺寸、缩放和背景色下的边缘。PNG 扩展名不能证明透明。保留状态图片相同的画布与视觉锚点，防止状态切换时图标跳动。

文字保持原生；设备插画不含标题、标签、单位或模拟读数。避免为每种语言复制图片。过细线条、微小图标和复杂阴影需在目标像素尺寸测试，不照搬桌面展示稿。

工艺图的接管位置、设备数量、阀门类型、传感器位置和支撑接触关系来自实际资料。检查连接连续性和遮挡：管道接到正确口，支脚接地，标签不穿过器件。技术未知项明确标记，不用视觉装饰补全工艺。

状态必须有清晰含义。运行色、报警色、禁用色、菜单选中色分别定义；条件允许时辅以文字或符号。环形显示的范围、零值、满量程、起点、方向及剩余/完成含义先定义，再做装饰。
