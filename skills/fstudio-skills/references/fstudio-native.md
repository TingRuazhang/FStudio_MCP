# FStudio 原生实现与排障

## 能力发现和执行生命周期

以当前工具 schema 和原生模型为准。不要把旧会话接口数量、控件数量或某型号测试结果推广为所有版本支持。

常见流程：连接宿主 → 打开工程 → 创建控件草稿 → 读取模型能力 → 设置有关联的属性 → 提交 → 保存 → 关闭重开回读 → 编译 → 运行检查。当前工具若提供 prepare/commit/discard，未完成草稿应明确处理。

返回 job_id 表示排队，轮询同一任务到终态；不要因没有立即看到变化而重复创建。批次写入前确认对象和字段，编译前确认保存。隔离编译通常使用磁盘快照，编辑器未保存的改动不会自动进入该快照。

重开工程后重新获取对象引用。引用失效或宿主管道失效时，先确认进程、插件加载、工作区和连接状态；普通方式打开 FStudio 不一定加载 MCP 宿主插件。不要为此反复改工程内容。

需要 UI 时使用宿主允许的桌面操作工具。每次实际操作后观察结果，不能使用过时窗口句柄或坐标。仅运行模拟器可执行文件可能只有空白窗口；优先使用 FStudio 自带离线模拟入口，确认工程被加载。

## 控件配置的依赖

数值显示与数值输入可能共享一个原生工具类，但模式不同。先显式选 Display/Input，再配置类型、地址、格式、键盘和限值。不要把同名字段的存在当成其已生效。

共用读写地址的控件可能不需要独立 WriteAddress。先读取是否独立读写的开关，再访问对应对象。需独立写地址时通过已支持的原生克隆/创建方法生成，避免直接解引用空 Raw。

显示类型、底层寄存器类型、字宽与字符长度各有含义，需一起核对。限值还要验证越界输入、取消和重开后的值；键盘配置正确不能替代实际点按验证。

地址清单至少包括：工程设备 ID、站号、寄存器区域、地址基准、长度、类型、缩放与读写权限。不同工程的设备 ID 不可照搬；Modbus 零基偏移与 4X 标签差一位的问题应通过实际映射核验。

## 原生文件修改

优先使用受支持的原生 API。必须离线修改 XML 时：

1. 确认目标工程关闭或已在隔离副本中；保留备份，避免磁盘改动被编辑器旧模型覆盖。
2. 采用当前版本原生保存的最小模板；保留命名空间、字段顺序、枚举和值类型。看起来相同的字符串不保证反序列化语义相同。
3. 区分控件身份与外部资源引用。控件唯一身份应唯一；图库、设备、语言资源等合法共享引用不能盲目重建，也不能因为相同就认定冲突。
4. 按稳定注释/业务标识查找唯一对象，缺失或重名则停止该修改。版本变化时先重新发现模型。
5. 原子保存后原生重开，读取最终属性再编译；XML 可解析只是最低限度检查。

不要绕过原生不支持的控件或保留页保护。支持声明需要包含具体配置和证据层级。若有替代实现，保持功能语义，并说明差异。

## 已观察的陷阱及证据边界

以下来自 FStudio 3.0.15685.0、F010 的开发记录。用于指导复现，不能视为所有版本的确定规则。

| 观察 | 当时确认的原因或边界 | 可迁移做法 |
| --- | --- | --- |
| 数字右侧单位被数字挤到左边 | 数值控件重开后将设定的 90 宽重新扩到 121，而单位未移动 | 依据最终尺寸分配数字与单位空间，勿把 121 当所有控件常量 |
| 子页透明但模拟背景黑 | 公共窗口背景属性未呈现预期底色；公共底层矩形在离线模拟中生效 | 对比公共属性与图元机制，并验证跨页层级和点击 |
| 单独启动 FSGUI 只有白窗 | 进程存在没有证明工程运行环境已加载 | 从工程的原生离线入口启动，实际查看内容 |
| 字体和文字观感与原型不符 | 曾调整字号、字体和边界，但没有单一根因对照试验证明“小数字号必然缺字” | 排查候选原因，每次只改变可解释的因素 |
| 文本库 ID 相同 | 合法系统资源也可能共享 ID | 不能只靠 ID 相同断言文字串扰 |
| 控件创建和保存成功但固件能力缺失 | 部分控件或可选模式不被原生编译器支持；历史数据显示某些搜索模式未输出 | 检查目标产物的字段，而非只检查成功返回 |
| 原生环形控件可运行但风格仍不像原型 | 动态功能与刻度、内圈、字重等视觉细节是独立验收项 | 原生功能保留，逐项补齐支持的视觉细节；不声称已达到 1:1 |

## 最小复现策略

先确认失败层：请求校验、异步执行、模型配置、保存重开、编译、运行、硬件。保留错误、对应对象、版本和相关配置，逐项缩减到一个控件。

对比“原生手工创建可运行样本”和“生成样本”的关键字段；不要随机枚举属性和值。被明确拒绝的能力若无新版本或新证据，不重复尝试相同参数。

修改一个根因后，重开相关对象并运行对应检查。涉及公共页面时扩大到受影响页面；涉及地址和类型时扩大到读写边界。避免因为修一个单位对齐而无目的重测全部平台接口。
